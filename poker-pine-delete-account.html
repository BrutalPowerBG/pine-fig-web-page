Delete your Poker Pine profile

This page is for the game Poker Pine, published by Pine Fig (PineFig). Follow the steps below to delete your profile and the personal data stored with it.

  1. Open Poker Pine.
  2. Go to the main menu.
  3. Open Profile.
  4. Tap Delete profile
  5. Confirm the deletion if the app asks you to.

The profile is deleted as soon as you confirm. You do not need to create an account or log in to request this.

What data is deleted or kept

Deleted immediately

  • Profile name and other profile details
  • Profile customizations, including card designs and avatar if you set them
  • Settings saved to that profile
  • Local game progress and statistics for that profile

Kept / extra storage

  • No personal data from the deleted profile is kept.
  • There is no additional retention period.
  • Uninstalling the app is not the same as deleting a profile. Use the steps above.

Request deletion by email

If you cannot use the in-app button, email us from the address tied to your play sessions and ask us to delete your Poker Pine profile.

contact@pinefig.com

We will handle email requests using that work address for Pine Fig. See also the PokerPine Privacy Policy.

Изтриване на профил в Poker Pine

Тази страница е за играта Poker Pine от разработчика Pine Fig (PineFig).

  1. Отворете Poker Pine.
  2. Отидете в главното меню (Main menu).
  3. Отворете Profile.
  4. Натиснете Delete profile
  5. Потвърдете изтриването, ако приложението поиска.

Изтрива се веднага: име и данни на профила, персонализации (включително дизайн на карти и аватар), настройки, локален напредък и статистика за този профил.

Не се запазва: лични данни от изтрития профил. Няма допълнителен период на съхранение.
